## 输出格式

以严格的 JSON 数组格式返回，每个元素是一个列定义：

```json
[
  {
    "col_name": "列名（保留原始列名或根据需求生成）",
    "semantic_type": "substrate_property | condition | gas_production | metadata",
    "unit": "期望单位（如 %、°C、ml/kg，如不确定留空字符串）",
    "description": "此列含义的简短中文说明",
    "expected_range": "合理数值范围（如 0-100、0-14，如不适用留空字符串）"
  }
]
```

## 语义类型说明

- **substrate_property**: 底物/原料的特性参数（如 TS、VS、C、N、含水率等）
- **condition**: 实验条件参数（如温度、pH、HRT、OLR、搅拌方式等）
- **gas_production**: 产气相关参数（如沼气产量、甲烷产量/含量等）
- **metadata**: 元数据信息（如数据来源、备注、文献信息等）

## 规则

1. 如果输入是 Excel 表头，请分析每列的语义含义并补全元数据
2. 如果输入是自然语言描述，请根据领域知识生成合适的列定义
3. 对于厌氧发酵领域，常见参数有：TS、VS、VS/TS、灰分、温度、pH、反应时间、HRT、OLR、C、H、O、N、TAN、S、C/N、VFA、F/I、SCOD、沼气产量、甲烷产量/含量等
4. 只返回 JSON 数组，不要包含任何其他文字
